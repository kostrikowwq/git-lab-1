# Нотатки з виконання роботи 
 
Під час виконання лабораторної роботи було успішно встановлено та налаштовано локальну систему git( вона була вже встановленна). 
Створено та клоновано публічний репозиторій з GitHub. 
Найбільш зрозумілою та зручною виявилася команда git status для контролю стану файлів. 
Труднощів під час виконання роботи не виникло.
